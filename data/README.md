# Minimal analysis tables

The two CSVs contain only `animal_id`, `group`, `endpoint`, `actual_time`, `time_unit`, `delta_T`. IDs were re-assigned specifically for publication; GI IDs preserve the original index ordering used by Stan and are not source-system identifiers. GI IDs denote repeated observations of the same mouse across two days; PE IDs denote distinct animals.

The source KWS Excel files, study protocols, animal-original codes and original worksheet coordinates are not distributed. These datasets were reduced from the NB05 validated inputs, without altering the ΔT values, group labels, sampling times or repeated-animal pairings.
